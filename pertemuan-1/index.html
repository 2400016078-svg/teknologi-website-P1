dibawah ini css dan html yang saya coba di W3Schools:

<style> di dalam head untuk Internal CSS.
W3Schools: HTML → HTML CSS

style="..." langsung di tag marquee untuk Inline CSS.
W3Schools: HTML → HTML CSS

font-family untuk mengganti jenis huruf.
W3Schools: CSS → CSS Fonts → Font Family

color untuk mengatur warna tulisan.
W3Schools: CSS → CSS Text → Text Color

text-align: center untuk membuat tulisan rata tengah.
W3Schools: CSS → CSS Text → Text Alignment

background-color untuk mengatur warna latar.
W3Schools: CSS → CSS Backgrounds → Background Color

rgb() untuk menentukan warna dengan angka merah, hijau, biru.
W3Schools: CSS → CSS Colors → RGB / RGBA

text-shadow untuk memberi bayangan pada tulisan.
W3Schools: CSS → CSS Text → Text Shadow

.foto-profil sebagai class selector untuk memberi gaya khusus pada foto.
W3Schools: CSS → CSS Selectors → Selectors

box-shadow untuk memberi bayangan pada foto.
W3Schools: CSS → CSS Shadows → Box Shadow

display: block, margin-left: auto, dan margin-right: auto untuk menengahkan foto.
W3Schools: CSS → CSS Image Centering

list-style-type dan list-style-position untuk mengatur titik daftar hobi.
W3Schools: CSS → CSS Lists → Styling Lists

padding-left: 0 untuk menghapus jarak bawaan daftar hobi.
W3Schools: CSS → CSS Padding → Padding

display: inline-block agar daftar hobi berada di tengah.
W3Schools: CSS → CSS Inline-block

<code> untuk menampilkan nama kode di bagian ini.
W3Schools: HTML → HTML Computercode

&lt;, &gt;, dan &rarr; untuk menampilkan simbol sebagai tulisan.
W3Schools: HTML → HTML Entities

onclick dan Date() pada tombol untuk menampilkan tanggal.
W3Schools: HTML → HTML JavaScript

<marquee> untuk teks berjalan.
